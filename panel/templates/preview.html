Packing

/screen.bin is 1 bit per pixel, MSB first, row-major, each row padded to a whole byte — framebuf.MONO_HLSB exactly. Byte index is y*{{.Stride}} + x/8, bit is 0x80 >> (x%8), and a set bit means a white pixel. Length is always ceil(w/8)*h = {{.BinBytes}} and it is sent with a real Content-Length, never chunked.
